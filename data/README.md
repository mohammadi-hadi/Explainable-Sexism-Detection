# Data

This directory holds the derived results behind the paper. It does not hold the
underlying shared-task corpora.

## What is not here

The EXIST and EDOS corpora are released by their organisers to registered participants
under their own terms, so they are not redistributed here. Those files also carry
material that does not belong in an open repository: the tweet text names accounts that
are still live, and the annotator records pair an identifier with gender, age,
ethnicity, study level and region.

| file | source |
|---|---|
| `EXIST2024_training_Task1.csv` | EXIST 2024, Task 1 training split |
| `df_lang_es.csv` | EXIST, Spanish subset |
| `train_all_tasks.csv` | EDOS, SemEval-2023 Task 10 |
| `train_df_augmented.csv` | back-translation augmentation of the two above |
| `final_dataframe_with_sexism_scores.csv` | per-tweet predictions, carries the tweet text |
| `final_dataframe_with_shap_scores.csv` | per-tweet attributions, carries the tweet text |
| `clean_data_en_demographic_statistics.csv` | per-annotator demographic records, English |
| `clean_data_es_demographic_statistics.csv` | per-annotator demographic records, Spanish |

They were removed from this directory on 7 August 2026. Earlier commits and the archived
Zenodo release still contain them: rewriting that history would break the DOI and the
citations that point at it, which is a worse outcome than leaving a record in place that
was already public.

## How to obtain them

- **EXIST 2023 and 2024** — register with the shared task at <http://nlp.uned.es/exist2024/>
  (2023 edition: <http://nlp.uned.es/exist2023/>) and accept the organisers' terms. They
  supply the training and test splits directly.
- **EDOS, SemEval-2023 Task 10** — <https://github.com/rewire-online/edos>.

Place the files in this directory under the names in the table above and the notebooks in
`../notebooks/` will find them. The four derived files (`train_df_augmented.csv`,
`final_dataframe_with_*_scores.csv`, and the two `clean_data_*_demographic_statistics.csv`)
are regenerated by the notebooks from the two sources.

## What is here

Aggregate results only. No tweet text, no annotator identifiers.

| file | contents |
|---|---|
| `significant_tokens.csv` | SHAP token importances over the test set |
| `important_words_general.csv` | top SHAP words, overall |
| `important_tokens1_es.csv` | top SHAP tokens, Spanish |
| `demographic_word_importance/` | per-group SHAP attributions, one file per group |
| `token_overlaps_Spanish.csv` | token-overlap matrix across categories |
| `coef_df.csv` | logistic-regression coefficients |
| `genai_results.csv` | scenario predictions |
| `ethics_reference.md` | data sources and the ethics statement |

Each of these is a word or token paired with a score, which is what the figures and tables
in the paper are drawn from. The analyses reported in the paper can be reproduced from
these without access to the raw corpora; only re-running the models requires the originals.
